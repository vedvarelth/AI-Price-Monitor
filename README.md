# Jacek Price Monitor

Prywatny, niekomercyjny prototyp do porównywania cen ofert Allegro.

## Cel
Wyszukiwanie produktów i porównywanie ceny produktu oraz kosztu dostawy
za pomocą oficjalnego Allegro REST API, w zakresie przyznanego dostępu.

## Sposób działania
Aplikacja będzie uruchamiana lokalnie przez właściciela.
Nie wykonuje automatycznych zakupów i nie zarządza ofertami sprzedawców.
Dostęp do wyszukiwania publicznych ofert wymaga uzyskania
odpowiedniej weryfikacji aplikacji przez Allegro.

## Status
Prototyp w przygotowaniu, wersja 0.1.0.
